# Citizen Assist AI — organização da Global Solution 2026.2

**PX é o nome provisório do produto. O nome deste repositório é apenas uma identificação acadêmica.** Empresa e produto ainda não têm nome definitivo. Não existe parceria, afiliação ou integração confirmada com o gov.br.

Este repositório organiza as entregas de um grupo de **3 integrantes**. Não contém implementações concluídas nem resultados de testes. Checklists representam trabalho a fazer; propostas de organização não são decisões do grupo.

## Limites do protótipo

O conceito amplo do PX poderá evoluir, mas as entregas acadêmicas têm requisitos próprios. Não será necessário integrar contas gov.br para atender aos enunciados recebidos. Público, funcionalidades adicionais, framework, modelo e financiamento continuam pendentes.

A base fictícia de Aurora **não é orientação pública real**. Ela deve permanecer isolada da base oficial de PCP. As análises estatísticas exigem dados reais; as fichas de Aurora e o cenário hipotético dos ônibus não atendem a essa exigência.

## Desenvolvimento e revisão

Criar uma tarefa por entrega, indicar responsável e revisor, trabalhar em branch e abrir pull request. Usar os modelos em `.github/`. Não marcar uma tarefa como concluída sem artefato e evidência. Este planejamento não equivale à entrega no Portal.

**Execução:** ainda não disponível. Os comandos reais serão documentados após a implementação. Em PCP, a versão de entrega deverá executar com `python main.py`, conforme o enunciado.
