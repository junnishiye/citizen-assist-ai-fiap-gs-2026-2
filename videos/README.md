# Controle de vídeos

| Entrega | Requisitos | Link / status |
|---|---|---|
| PCP | Técnico, 5–8 min, YouTube não listado, todos explicam código, sem narração sintética, alteração ao vivo, roteiro completo | Pendente |
| SERS | Técnico, ≤3 min, YouTube não listado, comparação/renovável e demonstração no assistente | Pendente |
| COA | YouTube, pode ser não listado; problema/circuito/lógica/entradas/saídas; duração não especificada | Pendente |
| DSA | Demonstração prática exigida; formato/duração de vídeo não especificados | Confirmar |
| Prompt e IA | Vídeo não explicitado no documento recebido | Confirmar Portal |
| Pitch da empresa/PX | Intenção no contexto, sem enunciado próprio recebido | Requisitos pendentes |

Reaproveitar preparação e capturas, mas gerar versões que cumpram cada rubrica. Nunca trocar o vídeo técnico PCP por um pitch comercial.
