# Data Structures and Algorithms

Fonte: [enunciado original](../fontes/enunciados/dsa.pdf), seções 3–7. Status: **planejado**. Responsável I1; revisor I2. Python é sugestão para compartilhar com PCP; o enunciado permite C ou Python.

- [ ] Definir recorte, campos dos registros e identificador único.
- [ ] Implementar nós com classes/objetos/referências em Python e lista encadeada explícita própria.
- [ ] Inserção, percurso e remoção reais na lista encadeada.
- [ ] CRUD completo: múltiplos cadastros, consulta por ID, atualização e exclusão mantendo integridade.
- [ ] Pesquisa por ≥1 atributo relevante, como título/categoria, com algoritmo próprio e caso sem resultado.
- [ ] Implementar ao menos um: Selection, Insertion, Merge ou Quick Sort. Uso exclusivo de ordenação pronta não atende; Bubble sozinho não está entre os algoritmos listados.
- [ ] Exibir ordenação por critério explicado.
- [ ] Menu: cadastrar, consultar, atualizar, excluir, pesquisar, ordenar, análise e encerrar.
- [ ] Análise útil: total, distribuição ou quantidade por categoria.
- [ ] Validar entradas, opções, IDs duplicados, inexistentes e lista vazia.
- [ ] Documentar modelo, encadeamento, fluxo do menu e instruções de execução.
- [ ] Big-O de inserção, busca, remoção e ordenação, justificado pela implementação real; considerar custo de verificar ID único ao cadastrar.
- [ ] Evidências com entrada, esperado e observado: casos normais, inválidos, inexistentes e operações em lista vazia.
- [ ] Demonstração das estruturas e algoritmos reais, além das telas.
